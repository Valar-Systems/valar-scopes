Blipscope Wi-Fi Field Test

Diagnostic firmware — blipscope-s3-128-joindiag, built from v11. These boards are test units and must be re-flashed to shipping firmware before going near a customer.
What you are trying to find out: whether the board that failed here is broken, or whether this network rejects Blipscopes. One board can't tell you. Four boards, all at the same place, can.

Before powering anything — the 2-minute check that could save the trip.
Look at each board's antenna: the ANT1/RF1 0-ohm link and whether the u.FL connector is fully clicked down. Photograph all four. If a link is in the wrong position or a u.FL is loose, that is the answer — stop and come home.

RUN A — their network exactly as it is

Do all four boards. Same procedure each time.

  1. Power the board. Wait for the yellow ** WIFI DIAG ** banner.
  2. On your phone, open Wi-Fi settings and connect to the hotspot matching the name on that board's screen (e.g. Blipscope-326E64).
  3. A setup page opens automatically. If not, browse to 192.168.4.1
  4. Enter their network name and password. Save.
  5. Now wait 12 minutes. Leave it alone. See the timing box below.
  6. Photograph the screen and fill in the row on page 3.
Twelve minutes, and don't cut it short. This is the whole reason the test exists — the original problem was called a failure after 30 seconds.

The board tries for about 1.5 minutes, shows the setup screen for 3 minutes, then restarts and tries again. One full round is about 5 minutes. You need at least two full rounds to tell "failed" from "still trying".

The cyc number on screen counts rounds. Wait until it reaches at least 3.

A blank or "Connecting to Wi-Fi..." screen is NOT a result. For the first ~1.5 minutes of every round that's normal. If it stays blank for more than 3 minutes, or cyc never changes, something went wrong with the test — note it as "no data", not as a failure.

RUN B — with 5 GHz paused

Only after Run A is finished and written down.

  1. Ask the owner to open the eero app and go to:
    Settings → Troubleshooting → "My device won't connect" → "My device is 2.4 GHz only"
    and pause 5 GHz and 6 GHz. This lasts 30 minutes.
  2. Note the time you started — everything must happen inside that window.
  3. Power-cycle all four boards (unplug, plug back in).
  4. Same as Run A: wait for cyc 3, photograph, record.
  5. Ask the owner to restore the setting when you're done. Don't leave their network changed.

What the combinations mean

If…Then
Suspect fails, known-good joinsThe board is faulty. Hardware — check its antenna. Question answered.
