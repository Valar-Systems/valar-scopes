# The game-config fixture moves to the served version 2 (predictions first)

**Why.** valar-eam-feed's `device-fixture-drift.yml` has failed daily, most recently run `40189699830` on
2026-10-25, with **exit 1: drift**, not exit 2 (no measurement). The committed `test/fixtures/game-config.json`
records config **version 1**, fetched 2026-08-18. The deployed service serves **version 2, epoch 1**, and its
`/status` reports commit `28034ba9d995a935fbf3f1d6061f72232a39f36e`, which is valar-eam-feed's `main`.

## The change

Both files are regenerated by the server's own generator. Neither is edited by hand.
- **The generator:** valar-eam-feed `scripts/emit-device-fixture.ts`, from a fresh clone at `28034ba`, the deployed
  commit, so its coherence check compares the served config against the code that is actually serving it.
- **The command:** `--out test/fixtures/game-config.json --header test/fixtures/game_config_fixture.h`.
- **`test/fixtures/README.md`'s provenance paragraph is updated.** It says `server_commit` is NULL because `/status`
  carries no commit, and that is no longer true.

of the served config that moved is the part no device test can see. That is reported as a finding, not fixed here.
